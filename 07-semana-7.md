# Semana 7

## 🎮 SPRINGTRAP SHOOTER 2D

Durante esta semana desarrollé un videojuego en **HTML, CSS y JavaScript** utilizando el elemento **Canvas** para crear una experiencia de disparos en 2D.

### Actividad

El proyecto consiste en controlar a Pac-Man, moverse por el escenario, apuntar con el mouse y disparar a los fantasmas.

### Controles

- **WASD / Flechas:** mover a Pac-Man.
- **Mouse:** apuntar.
- **Click / Espacio:** disparar.
- **P:** pausar.
- **Reiniciar:** comenzar una nueva partida.

### Características

- Sistema de puntos.
- 3 vidas.
- Niveles progresivos.
- Fantasmas como enemigos.
- Disparos.
- Efectos de partículas.
- Pantalla de pausa.
- Pantalla de Game Over.
