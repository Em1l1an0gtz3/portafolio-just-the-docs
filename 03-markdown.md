# Semana 2: Arduinos y circuitos

Durante esta semana trabajé con **Arduino UNO y circuitos electrónicos**, realizando diferentes prácticas para conocer las funciones básicas del microcontrolador, las conexiones de los componentes y la programación mediante Arduino IDE.

# Arduino, ¿qué es?

Arduino es una plataforma de hardware y software de código abierto que permite desarrollar proyectos electrónicos mediante la programación de una placa con un microcontrolador. En estas prácticas utilicé principalmente **Arduino UNO**, realizando circuitos sencillos y comprobando su funcionamiento por medio del código.

## ¿Cómo se utiliza Arduino IDE?

Primero se conecta la placa Arduino UNO a la computadora mediante un cable USB. Después se escribe el programa o *sketch* en Arduino IDE, se verifica que el código no tenga errores y finalmente se carga a la placa para comprobar el funcionamiento del circuito.

# Lista de materiales

## Arduino UNO

Placa con el microcontrolador que ejecuta los programas y controla los componentes del circuito.

## Cable USB-A a USB-B

Se utiliza para conectar el Arduino UNO a la computadora, cargar los programas y proporcionar alimentación a la placa.

## Protoboard

Tablero de pruebas que permite realizar conexiones de circuitos electrónicos sin necesidad de soldar.

## Jumpers

Cables utilizados para realizar las conexiones entre el Arduino, la protoboard y los diferentes componentes.

## LED

Diodo emisor de luz utilizado como indicador visual para comprobar las salidas digitales del Arduino.

## Resistencias

Componentes utilizados para limitar la corriente y proteger los elementos electrónicos. Se utilizaron resistencias de **1 kΩ y 220 Ω**.

## Display de 7 segmentos

Dispositivo formado por varios segmentos LED que permite representar números y algunos caracteres.

## Servomotor 9g

Motor que permite controlar la posición de su eje mediante señales enviadas desde el Arduino.

## Potenciómetro

Resistencia variable utilizada para modificar un valor de entrada y controlar diferentes comportamientos del circuito.

## Fuente de poder

Fuente utilizada para proporcionar alimentación eléctrica a los componentes cuando se requiere una alimentación externa.

## Push button (NO)

Botón normalmente abierto utilizado como entrada digital para enviar una señal al Arduino al ser presionado.
